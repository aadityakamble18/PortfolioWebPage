# Personal Portfolio Homepage

## Goal
Build a polished, responsive homepage inspired by the uploaded editorial layout, without embedding the screenshot itself.

## Page structure
- Slim top navigation with name and section links
- Bold opening statement paired with an abstract red portrait composition
- About section with concise biography and a resume link
- Projects preview with two large editorial case-study cards
- Footer with social links, professional website, and portfolio name

## Visual direction
- Warm off-white canvas, near-black typography, vivid red accent
- Oversized geometric sans-serif type with a compact editorial grid
- Thin red paths and layered floating shapes that drift subtly
- Sharp, print-inspired composition with restrained motion and strong mobile behavior

## Technical details
- Define all color, spacing, font, shadow, and motion tokens in the global design system
- Build only the home route and preserve future navigation targets as non-routing page labels
- Add homepage-specific search and social metadata
- Respect reduced-motion preferences and verify desktop and mobile layouts
